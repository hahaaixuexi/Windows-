## 正文（纯文本，直接复制）

远程开机最煎熬的不是等，是「它到底开了没」😤

写了个小脚本：电脑一开机，钉钉自动弹消息；断网就先记时间，联网后补发。已经开源，解压包直接能用👇

📦 部署流程（5 步，3 分钟）

1️⃣ 解压 ZIP 到 D:\DingBootNotify（别放 OneDrive，路径别有中文和空格）
2️⃣ 钉钉群 → 群设置 → 机器人 → 添加自定义机器人 → 选「加签」→ 复制 Webhook（开了加签再复制 SEC 密钥）
3️⃣ 双击 install.cmd，按提示粘贴 Webhook，一路回车；脚本会自动建好开机任务
4️⃣ Win+R 输入 taskschd.msc → 找到 DingBootNotify → 右键「运行」，群里收到消息
5️⃣ 重启电脑，30–60 秒内收到「开机提醒」就成功了

✨ 为什么用它
零依赖，只用 Windows 自带 PowerShell｜后台静默无黑框｜断网自动补发｜一条命令卸载

⚠️ 收不到消息？先看 logs\boot-notify.log，再去任务计划程序看「历史记录」。
