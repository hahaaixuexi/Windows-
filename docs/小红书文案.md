## 三、正文（完整版，约 850 字）

谁懂啊！远程开机最煎熬的不是等，是「它到底开了没」😤

跑渲染、跑训练、远程连家里主机，每次都要反复刷新。索性写了个开机通知脚本，现在电脑一开机，钉钉群立刻弹消息。整理成开源项目了，直接抄作业👇

📦 项目：DingBootNotify（Windows 开机自动钉钉推送）

✨ 能做什么
✅ 开机自动发消息，时间精确到秒
✅ 开机没网也不怕：先记时间，联网后补发
✅ 后台静默运行，不弹黑框
✅ 零依赖，只用系统自带 PowerShell
✅ 一键安装，随时可卸载

🧭 一步一步流程（照做就行）

1️⃣ 建机器人
钉钉群 → 群设置 → 机器人 → 添加自定义机器人 → 安全设置选「加签」→ 复制 Webhook 和 SEC 密钥

2️⃣ 拿代码
GitHub 搜 DingBootNotify，clone 或下 ZIP

3️⃣ 填配置
打开 config.json，粘贴 webhook 和 secret，设备名随手写一个

4️⃣ 装任务
双击 install.cmd，自动提权 → 复制文件 → 创建开机任务（SYSTEM 账户，不登录也运行）

5️⃣ 验证
任务计划程序里右键「运行」，钉钉秒收消息；再重启一次，确认开机也能收到

🔧 想手动装？
docs/手动部署.md 有纯图形界面版：建文件夹 → 放 3 个文件 → 任务计划程序建「计算机启动时」任务 → 勾「不管用户是否登录」+「最高权限」+ 取消「仅交流电源」。

⚠️ 踩坑预警
· errcode 310000：99% 是脚本编码不对导致中文乱码。这个项目把中文全放进 config.json，主脚本纯英文，从根上绕开
· 收不到消息：先去任务计划程序看「历史记录」，确认任务真被触发
· 别把 webhook 提交到公开仓库，泄露会被人调用

电脑开机，钉钉自动发消息，我终于不用反复问「开了没」了。

开源项目 DingBootNotify，零依赖，只用 Windows 自带 PowerShell。

流程就 5 步：
① 钉钉群建自定义机器人，拿 Webhook
② 下载仓库
③ 填 config.json
④ 双击 install.cmd，自动创建开机任务
⑤ 任务计划程序右键运行验证

断网会先记开机时间，联网后补发；后台运行无黑框；一条命令卸载。
