# 从解压包部署（5 步，约 3 分钟）

适合不想碰命令行的朋友：下载 ZIP → 解压 → 双击 → 完成。

**准备**：Windows 10 / 11、管理员权限、一个钉钉群（你有权添加机器人）。

---

## 第 1 步：解压

1. 右键 `DingBootNotify-v1.0.0.zip` →「全部解压」
2. 目标目录填 `D:\DingBootNotify`（路径尽量没有中文和空格）
3. **不要**放在 OneDrive / 坚果云等同步盘里：开机任务以 SYSTEM 运行，读不到云端占位文件
4. 如果 Windows 提示「已保护你的电脑」或脚本被拦截：右键 ZIP →「属性」→ 勾选「解除锁定」→ 重新解压

解压后目录里应有：

```
D:\DingBootNotify\
├─ DingBootNotify.ps1
├─ RunNotify.vbs
├─ config.example.json
├─ install.ps1
├─ install.cmd
├─ uninstall.ps1
└─ docs\
```

---

## 第 2 步：创建钉钉机器人

1. 钉钉群 → 右上角「群设置」→「机器人」→「添加机器人」→「自定义」
2. 安全设置选 **加签**（推荐）
3. 复制 **Webhook 地址**；如果选了加签，同时复制 `SEC` 开头的**密钥**

---

## 第 3 步：双击 `install.cmd`

1. 弹出 UAC 提示 → 点「是」
2. 提示「请粘贴钉钉机器人 Webhook」→ 粘贴后回车
3. 提示加签密钥 → 有就粘贴，没有直接回车
4. 提示设备名称 → 直接回车（默认用电脑名）
5. 提示「现在发送一条测试消息？」→ 直接回车

脚本会自动完成：复制文件 → 生成 `config.json` → 创建开机任务 `DingBootNotify`（SYSTEM 账户，无需登录即运行）。

---

## 第 4 步：确认任务

`Win + R` → 输入 `taskschd.msc` → 回车，打开「任务计划程序」：

1. 左侧「任务计划程序库」找到 `DingBootNotify`
2. 右键 →「运行」
3. 钉钉群收到消息 → 说明配置生效

> 没收到：看 `D:\DingBootNotify\logs\boot-notify.log` 的报错；`errcode 310000` 通常是加签密钥填错。

---

## 第 5 步：重启验证

重启电脑（不是关机再开，快速启动可能不算真正的启动事件），等待 30–60 秒：

- 网络正常 → `【开机提醒】设备名 已开机`
- 网络慢 → `【开机提醒】设备名 延迟推送`（默认最多等 10 分钟）

收到任意一条即部署完成。

---

## 日常使用

| 事情 | 怎么做 |
| --- | --- |
| 改设备名 / 消息模板 | 编辑 `D:\DingBootNotify\config.json`，然后右键任务「运行」验证 |
| 看运行记录 | `D:\DingBootNotify\logs\boot-notify.log` |
| 改等待时长 | `retryMaxSeconds`（秒），如 `900` = 15 分钟 |
| 卸载 | 管理员 PowerShell 运行 `.\uninstall.ps1 -RemoveFiles` |

更细的排查见 [常见问题.md](常见问题.md)；想改成纯手动建任务见 [手动部署.md](手动部署.md)。
