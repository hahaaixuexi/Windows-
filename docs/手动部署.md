# 手动部署（纯图形界面，不用安装脚本）

适合不想运行 `install.ps1`、想自己掌控每一步的人。全程约 8 分钟。

> 如果你只是想快点用起来，回到 [README](../README.md) 用 `install.cmd` 一键安装即可，下面的步骤它都替你做了。

---

## 第 0 步：准备

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| 权限 | 管理员 |
| 钉钉 | 一个群，且你有权限添加机器人 |
| 目录 | 建议 `D:\DingBootNotify`（无空格、非中文路径最稳） |

本项目的脚本全部使用**相对路径**（`$PSScriptRoot`），放在哪个盘都能跑，移动目录后只需同步修改任务里的路径。

---

## 第 1 步：创建钉钉机器人

1. 打开钉钉群 → 右上角「群设置」
2. 左侧「机器人」→「添加机器人」→ 选择「自定义」
3. 机器人名字随意，例如 `开机提醒`
4. 安全设置三选一，推荐 **加签**：
   - 加签：复制 `SEC` 开头的密钥，填到 `config.json` 的 `secret`
   - 关键词：消息里必须包含关键词（本项目默认消息含「开机提醒」，可填这个）
   - IP 地址段：家用宽带 IP 会变，不推荐
5. 勾选协议 → 完成 → **复制 Webhook 地址**（`https://oapi.dingtalk.com/robot/send?access_token=...`）

---

## 第 2 步：放置文件

在 D 盘新建文件夹 `DingBootNotify`，把仓库里这 4 个文件放进去：

```
D:\DingBootNotify\
├─ DingBootNotify.ps1    主脚本
├─ RunNotify.vbs         隐藏窗口启动器
├─ config.example.json   配置模板
└─ config.json           由模板复制而来（下一步填写）
```

操作：复制 `config.example.json` → 在同一目录粘贴 → 重命名为 `config.json`。

---

## 第 3 步：填写 config.json

用记事本打开 `config.json`，至少填 `webhook`：

```json
{
  "webhook": "https://oapi.dingtalk.com/robot/send?access_token=你复制的token",
  "secret": "SECxxxxxxxx（没开加签就留空）",
  "deviceName": "工作站-01",
  "onlineTemplate": "【开机提醒】{device} 已开机\n开机时间：{bootTime}\n发送时间：{sendTime}",
  "delayedTemplate": "【开机提醒】{device} 延迟推送\n记录开机时间：{bootTime}\n联网发送时间：{sendTime}",
  "retryMaxSeconds": 600,
  "retryStepSeconds": 5
}
```

注意：

- 保存编码选 **UTF-8**（记事本默认即是；带不带 BOM 都能读）
- `\n` 要保留为两个字符（反斜杠 + n），这是 JSON 的换行写法，不要改成真换行
- 反斜杠路径如果自己加字段，记得写成 `D:\\xxx`

### 编码对照表

| 文件 | 推荐编码 | 说明 |
| --- | --- | --- |
| `DingBootNotify.ps1` | 任意 | 纯 ASCII，改中文进去才需要注意 |
| `RunNotify.vbs` | ANSI / ASCII | 纯 ASCII，UTF-8 无 BOM 也等价 |
| `config.json` | UTF-8 | 中文消息都在这里，脚本按 UTF-8 显式读取 |
| `install.ps1` / `uninstall.ps1` | UTF-8 **带 BOM** | 含中文提示，PS 5.1 需要 BOM；仓库文件已处理好 |

---

## 第 4 步：本地功能测试（先别急着建任务）

打开 PowerShell，执行：

```powershell
cd D:\DingBootNotify
powershell -ExecutionPolicy Bypass -File .\DingBootNotify.ps1 -DryRun
```

`-DryRun` 只打印消息、不真的发钉钉，用来确认配置能读、模板能渲染。

再去掉 `-DryRun` 真发一条：

```powershell
powershell -ExecutionPolicy Bypass -File .\DingBootNotify.ps1
```

或者直接**双击 `RunNotify.vbs`**：不会弹任何窗口，几秒后钉钉群收到消息，说明文件与配置都正常。

失败就看日志：`D:\DingBootNotify\logs\boot-notify.log`。

---

## 第 5 步：创建开机任务

1. 按 `Win + R`，输入 `taskschd.msc`，回车，打开「任务计划程序」
2. 右侧操作栏 →「创建基本任务」
3. **名称**：`DingBootNotify`；**描述**：`开机自动发送钉钉通知` → 下一步
4. **触发器**：选择「当计算机启动时」→ 下一步
5. **操作**：选择「启动程序」→ 下一步
6. **启动程序**：
   - 程序或脚本：`wscript.exe`
   - 添加参数：`"D:\DingBootNotify\RunNotify.vbs"`（路径有空格必须带引号，没有空格也建议带上）
   - 起始于：留空
   - 下一步
7. 勾选「点击完成时，打开属性对话框」→ 完成

### 在属性窗口改 3 个选项卡

**【常规】**

- 勾选「不管用户是否登录都要运行」
- 勾选「不存储密码」
- 勾选「使用最高权限运行」

> 更省事的替代方案：点「更改用户或组」→ 输入 `SYSTEM` → 确定。SYSTEM 账户开机即运行，不依赖任何用户登录状态。

**【条件】**

- 取消「只有计算机使用交流电源时才启动此任务」（笔记本用电池也能发）
- 其余保持默认

**【设置】**

- 勾选「允许按需运行任务」
- 勾选「如果任务失败，按以下频率重新启动」：间隔 `1 分钟`，尝试 `3` 次
- 可选：把「如果任务运行时间超过以下时间，停止任务」改为 `30 分钟`

点「确定」保存。

---

## 第 6 步：测试任务

在「任务计划程序库」找到 `DingBootNotify` → 右键 →「运行」。

- 钉钉群收到消息：任务配置生效
- 没收到：右键 →「历史记录」，看任务是否真的被触发；再对照 `logs\boot-notify.log`

---

## 第 7 步：整机验证

重启电脑，等待 30–60 秒（系统联网需要时间）：

| 场景 | 预期消息 |
| --- | --- |
| 网络正常 | `【开机提醒】设备名 已开机` |
| 网卡 / Wi-Fi 加载慢 | `【开机提醒】设备名 延迟推送`，默认最长等 10 分钟 |

延迟推送说明：脚本先把真实开机时间写进 `state\pending-boot.txt`，联网成功后补发并自动删除该文件。

---

## 卸载

方式一（图形界面）：

1. `taskschd.msc` → 删除任务 `DingBootNotify`
2. 删除整个 `D:\DingBootNotify` 文件夹

方式二（脚本）：

```powershell
cd D:\DingBootNotify
.\uninstall.ps1 -RemoveFiles
```
